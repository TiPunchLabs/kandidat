Aide

Guide d'utilisation

kandidat est une interface web personnelle pour suivre et gerer vos candidatures. Voici comment utiliser chaque fonctionnalite.

Demarrage rapide

  1. Creer une cible — Allez dans Cibles et ajoutez une entreprise (nom, categorie, site web).
  2. Creer une candidature — Cliquez sur Nouvelle, selectionnez l'entreprise cible, renseignez le poste et joignez vos fichiers (CV, LM, offre).
  3. Suivre l'avancement — Depuis la fiche candidature, changez le statut au fur et a mesure (envoyee, relancee, entretien...).
  4. Consulter le dashboard — La page d'accueil affiche un tableau de toutes vos candidatures, filtrable et triable.

Dashboard

Page d'accueil avec une vue d'ensemble de toutes vos candidatures.

  • Barre de KPI en haut : total, envoyees, entretiens, relances
  • Tableau filtrable par statut, type, priorite, categorie
  • Tri par colonne (cliquez sur les en-tetes)
  • Cliquez sur une ligne pour ouvrir la fiche candidature
  • Bouton Regenerer pour exporter vers Obsidian (fichier 00-Dashboard.md)

Candidatures

Chaque candidature est rattachee a une entreprise cible.

CreerMenu Nouvelle — remplissez entreprise, poste, type, priorite et selectionnez une cible
FichiersDepuis la fiche, uploadez CV, lettre de motivation, offre d'emploi ou tout autre document
Changer le statutPanneau lateral droit — selectionnez le nouveau statut (avec commentaire optionnel)
ArchiverBouton en bas de la fiche — archive la candidature (irreversible)
SupprimerBouton en bas de la fiche — supprime definitivement la candidature

Cycle de vie des statuts

Les transitions de statut suivent des regles precises. Seuls certains enchainements sont autorises :

brouillon → envoyee → relancee → entretien → acceptee → archivee
                                       → refusee → archivee
                         → sans-reponse → archivee

Cibles (entreprises)

Les cibles sont les entreprises que vous visez. Chaque candidature doit etre rattachee a une cible.

  • Ajoutez une cible avec son nom, categorie (startup, PME, groupe, autre), site web, email, LinkedIn
  • Cliquez sur une cible pour voir sa fiche detaillee et gerer ses contacts
  • Ajoutez des contacts (nom, prenom, email, telephone, LinkedIn, fonction)
  • Creez une candidature directement depuis la fiche cible
  • Une cible avec des candidatures existantes ne peut pas etre desactivee

Fonctionnalites IA (optionnelles)

Ces fonctionnalites necessitent une configuration prealable dans Parametres.

Adaptation de CV

  • Prerequis : uploader un CV de reference (HTML) dans les parametres + configurer un fournisseur LLM
  • Depuis la fiche candidature, cliquez sur Adapter mon CV
  • Le LLM adapte votre CV au poste et a l'entreprise
  • Previsualisation dans un iframe — confirmez pour sauvegarder en PDF et DOCX

Enrichissement de cible

  • Prerequis : configurer une cle API Tavily + un fournisseur LLM dans les parametres
  • Depuis la fiche cible, cliquez sur Enrichir via IA
  • Recherche web automatique (Tavily) + extraction structuree (LLM)
  • Preview avec cases a cocher pour selectionner les infos et contacts a importer

Parametres

CV de referenceUploadez votre CV au format HTML — il servira de base pour l'adaptation IA
Fournisseur LLMChoisissez entre Ollama (local) ou Claude (API distante) — bouton de test de connectivite inclus
Prompts personnalisesModifiez les prompts systeme et utilisateur pour l'adaptation CV (bouton reset vers les valeurs par defaut)
TavilyRenseignez votre cle API Tavily pour activer l'enrichissement de cibles

Recherche et statistiques

  • Recherche — recherche plein texte dans les noms d'entreprise, postes et contenus. Accessible via le menu ou le raccourci /
  • Statistiques — graphiques de repartition par statut, type, priorite et categorie. Timeline chronologique de vos candidatures

Themes

4 themes disponibles, selectionnables en bas de la barre laterale :

PrecisionTheme par defaut, tons neutres et sobres

Raccourcis clavier

API et MCP

kandidat expose une API REST complete (/api/) et un serveur MCP (port 3001) pour l'integration avec des agents LLM.

  • API REST : CRUD candidatures, cibles, contacts, recherche, statistiques
  • Serveur MCP : 22 outils accessibles par les agents IA (Claude Desktop, Claude Code...)
  • Configuration MCP : {"url": "http://127.0.0.1:3001/mcp"}
